# Blinkit Sales Analysis Dashboard (Power BI)

## 📌 Project Overview
This Power BI project analyzes Blinkit (formerly Grofers) grocery sales data to uncover 
business insights such as:
- Total revenue and number of products sold
- Fat content contribution (Low Fat vs Regular)
- Performance by Item Type
- Outlet size and location-based sales patterns

The dashboard enables data-driven insights for business decisions.

---

## 📊 Key Features in the Dashboard
- ✔ KPI Cards (Total Sales, Number of Items)
- ✔ Interactive Slicers (Outlet Location Type, Outlet Size, Item Type)
- ✔ Item Type Sales Performance Visualization
- ✔ Fat Content Distribution Analysis
- ✔ Outlet Size & Location Impact Study
- ✔ User-friendly dashboard layout
